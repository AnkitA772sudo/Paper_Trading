# PaperTrade 📈

PaperTrade is a virtual stock trading simulator built for learning and practicing stock market investing without risking real money.

The platform allows users to create an account, manage a virtual balance, buy and sell stocks, track portfolio performance, and compete with other traders on a leaderboard. It is designed to give users a realistic trading experience while keeping everything completely risk-free.

## Features

* User authentication (Sign Up & Login)
* Virtual trading with a starting balance
* Real-time stock search and selection
* Buy and sell stock simulation
* Interactive stock price charts
* Portfolio tracking with profit/loss calculations
* Transaction history
* Trader leaderboard
* Dark and light theme support
* Local data storage for user accounts and trading records

## Built With

* HTML
* CSS
* JavaScript
* Chart.js

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Run the application using a local server.
4. Open the website in your browser.

## Purpose

This project was created to practice web development concepts while building a stock market simulation platform. It focuses on portfolio management, trading logic, data visualization, and user experience.
